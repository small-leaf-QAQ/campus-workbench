# 校园生活工作台 · 使用手册

> 一句话：**课表、DDL、长任务拆解、邮件提醒**都在一个页面里；QQ 上还能直接问它「明天有什么课」。

---

## 一、入口与总览

**访问地址**

```
你部署好的那个域名，形如 https://xxxx-12345.app.workbuddy.host/
```

> 只是双击本地文件打开的话，看到的是演示模式（示例数据，只存本机），不需要登录。
> 下面说的登录流程只在接入云数据库后才出现。

### 第一步：登录（不登录看不到任何内容）

打开链接先看到的是一个**登录页**：左边黑底写着「校园生活工作台」，右边是登录框。

1. 填**手机号** → 点「获取验证码」→ 收短信 → 填**验证码** → 点「登录 / 注册」
2. 或者点「**微信登录**」——电脑上会出现二维码，用手机微信扫一下即可

> **手机上为什么微信登录要另一台设备扫？**
> 微信的网站扫码登录在手机浏览器里只给二维码，而二维码就在你自己这块屏幕上，扫不到。
> 可行的路：用另一台设备（电脑、平板、家人的手机）的微信扫；或者直接用手机号验证码登录。
> 注意**微信账号和手机号账号是两套身份**，数据互不相通，选定一种就别换。

**第一次用会自动注册**，不需要单独设密码。

> 为什么必须先登录：你的课表和 DDL 存在云端、按账号隔离。没登录的话，系统不知道要给你看谁的数据——所以它会**完全不显示内容**，而不是给你看一份别人的或空白的。

### 登录之后

- 数据存在**云端**，跟着**账号**走 —— 换个设备、换个浏览器，登录同一个账号就能看到自己的东西。
- **界面长这样**：左边一列竖排的**卡片**是导航，右边大块是当前功能的内容区。
  手机上门导航会收进**屏幕底部的图标栏**，内容照常整屏显示。
- **左侧六张卡片**就是六个功能，图标在上、文字在下；当前选中的那张会**放大并变成红底白字**，鼠标移上去另外几张也会轻轻浮起。分别是：

| 标签 | 干什么 |
|---|---|
| **今天** | 今日课程 + 今天要处理的任务（逾期置顶）+ 进行中的长任务 |
| **课表** | 周视图课表，可翻 1–20 周；导入课表截图 / 手动加课 |
| **DDL 管理** | 所有待交任务；导入通知 / 手动添加；按「今日 / 本周 / 未来 / 逾期」四栏看 |
| **长任务拆解** | 大作业的阶段性规划；生成拆解方案 / 日程规划 / 新建长任务 |
| **收件箱** | QQ 机器人收到的消息落在这里，待你确认或转成任务 |
| **邮件提醒** | 每日推送的订阅设置 + 邮件正文预览 |

- **内容区顶部**有一条工具栏：一个**同步状态点**、**刷新**、**备份**。
  那个小圆点平时不占地方，出问题才展开成文字；**点它**能打开「数据与账号」抽屉——数据源说明、登录 / 退出、从备份恢复、清空示例数据都在那里。
- 页面上任何**看不清、不敢写死**的字段都会标成「待确认」「请人工核实」，而不是替你猜。

## 二、第一次用：三步

### 第 1 步 · 打开页面并登录
直接访问上面的地址，用**微信或手机号**登录。登录后看到的是**你自己账号名下**的数据。

### 第 2 步 · 设学期锚点（很重要，只做一次）
课表页 → 右上角 **「学期设置」** → 填 **「第 1 周周一」**（本学期第一周的周一日期）。

> 这是「今天在第几周」的**总开关**，填错了整季的课表都会整体偏位。
> 不用算它是哪一天 —— **填本学期第 1 周的任意一天**，页面会自动对齐到那一周的周一。
> 换设备时，导出的备份里也带着这个值。

### 第 3 步 · 把课表弄进来
课表页 → **「导入课表截图」** → 选课表截图 → 等识别 → **逐条复核** → 确认写入。

- 识别出来的每条都有来源、可改；周次认不出的会标「没写周次（按每周都有处理）」，绝不会顺手猜。
- 同一天同一节次但**周次不重叠**的两门课，是正常的周次切换，不会被当成冲突报错。
- 也可以用 **「添加课程」** 手动一条一条加。

## 三、日常怎么用

### 今天（首页）
- **今日课程**：按「今天星期几 + 今天在第几周」过滤 —— 本周不上这门课就不会出现。
- **今天要处理**：按紧迫度与重要度综合排序，**已逾期置顶**。
- **进行中的长任务**：只显示当前正在推进的阶段，后来还没轮到的不会来打扰你。

### 课表
- 顶部是一条**周次滚轮**：左右箭头翻周，中间 20 格数字就是 1–20 周。**有课的那一周，数字底下带一颗小点**；当前查看的周是红方块，本周是红色数字。
- 只有本周会上的课才显示；非本周时**不高亮今天列**。
- 滚轮下面一行写清这一周的范围和门数，例如「10/19 – 10/25 · 5 门课 · 本周」；右侧还会提示有几门课不在本周（周次范围外，已隐藏）。
- 翻到别的周才会出现「**回到本周**」，点一下就回来。手机上一屏放不下 20 格，左右滑动即可，当前周会自动居中。

### DDL 管理
- **导入通知**：把班级群的通知**文字**或**截图**丢进去，模型提取「任务名称 / 所属课程 / 截止时间 / 提交方式」。
- **手动添加**：自己填。
- 四栏：**今日 / 本周 / 未来 / 逾期**；已完成的收进右上角「**已完成 N**」归档，点开可看全部已完成任务。
- 每条都带 **重要度**（高/中/低）与 **来源摘录** —— 出问题能回溯到原话。

### 长任务拆解
1. **生成拆解方案**：填总任务名（可从已有 DDL / 已有长任务点选）→ 选时间锚点（按 DDL 截止日倒排 / 从今天正排）→ 交给任务拆解师 → 审核 → 写入。
2. **日程规划**：让日程规划师按课表空闲时段，把阶段排到具体日期与节次。
3. **新建长任务**：手动加一个总任务。
- 阶段状态跟着依赖链走：前一个完成，下一个才自动变「进行中」。

### 收件箱
QQ 机器人收到的每条消息都会先落在这里（**待处理 / 已处理 / 已忽略 / 全部**）。
- 想手工补一条，用 **「粘贴一条消息」**。
- 待处理的可以 **「转成任务」**，直接变成 DDL 或长任务阶段。

## 四、邮件提醒怎么设

邮件提醒页从上到下：

| 项 | 说明 |
|---|---|
| **提醒邮箱** | 收件人。填你自己的常用邮箱 |
| **每日推送时间** | 只认**整点**（工作站每小时检查一次，非整点会向下取整，界面上显示的就是实际发送时间） |
| **每日 DDL 汇总推送** | 总开关，关掉就整封不发 |
| **截止倒计时提醒** | 开：块一显示「未来 N 天」；关：块一只留「今天到期」 |
| **长任务节点提醒** | 开：邮件里才有第三块（长任务阶段） |
| **提前提醒天数** | 「未来 N 天」的 N，0–30，默认 7 |
| **保存设置到云端** | 保存后即生效，工作站会把你纳入推送名单 |

### 邮件正文有哪几块

```
主题：【校园生活工作台】10月15日 周三 · 今日提醒（3 项待办）

〇、逾期未完成（1 项）      ← 有逾期才出现，且**置顶**
一、DDL 倒计时（未来 7 天）
二、当日课表（周三）
三、今日该推进的长任务阶段
        ⚠ 已落后计划（1 个阶段）   ← 计划结束日已过但还没做完的阶段
```

- **逾期单独置顶**：逾期项混在「未来 N 天」里最容易被眼睛跳过。
- **已落后计划**：计划窗已经关上、既不算「正在推进」也不算「即将开始」的阶段 —— 这类最该被提醒，所以单独列出来。
- 计划时间**都是估算**，逐条标注依据，请人工核实。

### 谁收到什么
- **按账号独立判定**：每个人用**自己的账号**登录、填**自己的邮箱**，就收到**自己的**课表与待办。
- 发件人永远是**工作站绑定的那个邮箱**。
- 每天每人**只发一封**（当天已发过就跳过，所以同一天不同人分别收到是正常的）。

**别人怎么开（三步）**：打开同一个网址 → 注册登录自己的账号 → 邮件提醒页填自己的邮箱并保存。完。

### 到了时间没收到？
- 工作站在**这台电脑上**跑，**每小时检查一次**。本机**睡眠或关机期间不执行**定时任务；醒来后因为判定是「到点且当天没发过」，会**补发**。
- 页面「定时推送计划」里能看到订阅状态、推送内容、今天状态（已发送 / 待发送 / 不发信）。

## 五、QQ 机器人「工作台小助手」

### 怎么用
- **私聊**：直接说，不用 @。
- **群里**：必须 **@机器人**。

### 它能做两件事

**① 记任务**（会写库）
发文字、截图、语音、**合并转发**的聊天记录都行。它会判断：
- 单点截止的 → 写进 **DDL 任务**
- 要拆多阶段的 → 写进 **长任务拆解**
- 课表 → 写进 **课程表**
- 每条消息**先落收件箱**，再决定去向
- 信息明确直接入库；**日期要推算 / 指向含糊 / 要拆多阶段 / 要改动已有记录**时，会先把草稿挂起并回你一句确认

**② 回答查询**（只读，不写任何东西）
可以直接问：
- 「明天有什么课」「这周还有几节课」
- 「这周还要交什么」「哪门课还有作业」
- 「我是不是有东西落后了」
- 「有什么挂起等我确认」

回答会带上日期与周次；答不上的它会说答不上来，不会编。

### 两个坑
- **千万别开「获取群内全部消息」** —— 开了机器人会彻底哑掉。
- 合并转发里的**每条消息 = 一条独立收件箱记录**，但**不带发送时刻**，所以里面的「明天」「下周三」这类相对日期推不出来（它会问你或标待确认）。

### 机器人显示「该机器人的'灵魂'不在线」
这是它到 QQ 的**长连接断了**（网络抖动导致，不是配置错）。修法：
1. 助理设置 → QQ 机器人 → **断开 → 重新连接**；
2. 还不行就**重启 WorkBuddy**（数据都在云端，不会丢）。

## 六、数据在哪、怎么备份

- 云端五张表：**课程表 / DDL 任务 / 长任务拆解 / 提醒设置 / 群消息收件箱**，都挂在同一个应用下，**按账号隔离**。
- **内容区顶部的「备份」** 导出**全部数据的 JSON 快照**（含学期锚点）。换设备后导入即可，若文件里的学期锚点和当前不一致，页面会提示你并一并采用。
- **「刷新」** 重新拉一次云端数据。
- 数据**存在云端**，没有「离线版」—— 接入云数据库后，页面不再把数据写进浏览器。断网时用不了，恢复网络后点刷新即可（云端数据不会因为断网丢失）。
  > 例外：如果文件里没填云配置，页面会进入**演示模式**，那时数据确实存在浏览器本地，左上角会写明「演示数据 · 仅本机」。
- 页面顶部的状态点变红并展开文字时，说明会话掉了或同步出错，点一下能看原因并重新登录。

## 七、遇到问题

| 现象 | 怎么办 |
|---|---|
| 课表整体偏了一周 | 课表页 → 学期设置 → 改「第 1 周周一」 |
| 同一时段显示两门课 | 正常 —— 周次不重叠就是周次切换；真的重叠会标成冲突 |
| 邮件预览里看到一门「不该有」的课 | 先看「课表」页本周是否上它；预览与真发信是同一套口径 |
| 邮件没收到 | 查①邮箱填没填 ②总开关开没开 ③是否到点 ④本机是否睡眠 |
| 任务一直「待确认」 | 它没在你的话里找到确凿依据，人工补一下就好 |
| 打开链接只看到登录页 | 正常 —— 必须先登录。手机号验证码或微信登录都行 |
| 收不到短信验证码 | 确认手机号是 11 位；等一分钟再点「重新获取」；换「微信登录」也行 |
| 微信登录跳转后没回来 | 回到原链接再登录一次（授权码一次性，被拦下就失效） |
| **登录后换个标签页回来又要登录** | 这个环境**存不住登录状态**（应用内预览窗口、沙箱内嵌页、无痕模式都会如此）。登录页上会有一行红字提示，照它给的地址用**浏览器新标签页**打开即可 |
| 微信登录报「requires an absolute redirectTo」 | 同上，是环境拿不到真实域名导致的，已修；仍出现就用手机号验证码登录 |
| 用着用着弹出登录页 | 登录状态过期了，重新登录即可，云端数据不会丢 |
| 页面白屏 / 数据没出来 | 点内容区顶部的「刷新」；再不行重新登录 |
| 微信里点链接打不开 | 用手机浏览器打开（微信内置浏览器可能拦），或点右上角「在浏览器中打开」 |
| 机器人不理我 | 见上面「灵魂不在线」 |

## 八、它为什么老说「待确认」

这是**故意**的，两条原则：

1. **不编造**。解析不出来的字段宁可留空或标「待确认」，也不会填一个看起来合理的假值。
2. **时间都是估算**。拆解与排期依据经验值给出，逐条写明「预估依据」，请你人工核实后再当承诺。

所以它偶尔会问你一句、或者把一条挂起等你确认 —— 那不是在偷懒，是在避免往你的计划里掺假。
