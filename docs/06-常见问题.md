# 常见问题

按「你现在看到什么」查。

---

## 打开相关的

### 双击打开是一堵登录墙，进不去

你拿到的是**已经填过云配置**的版本（通常是作者自己部署的那份）。

两个选择：

- 想先看效果 → 用仓库里这份 `index.html`（`CLOUD_CFG` 两个值为空 → 自动演示模式）
- 想连自己云端 → 看 [部署到云端](02-部署到云端.md)

### 双击打开是空白页

| 可能 | 怎么确认 |
|---|---|
| 文件没解压完 / 下载不完整 | 看文件大小，应该 500KB 以上 |
| 浏览器拦截了本地脚本 | 按 F12 看 Console 有没有报错 |
| 用别的程序打开了 | 右键 → 打开方式 → 浏览器 |

Safari 用户在 macOS 上偶尔会用文本编辑器打开 `.html`，表现就是一片代码。

### 手机上能打开吗

- **本地文件**：iOS 不能直接双击本地 HTML，需要放到网盘或服务器上（见 B / C 方式）
- **已部署的域名**：能，页面做了手机适配，课表自动变成一天一屏

### 打开是演示模式，我想连云端

说明 `CLOUD_CFG` 两个值里至少有一个是空的。检查：

```js
var CLOUD_CFG = {
  endpoint: 'https://你的域名',        // 结尾不要带 /
  publishableKey: 'wbpk_xxxx'          // 必须和 endpoint 同一个应用
};
```

填完要**重新发布**一次，否则线上还是旧文件。

## 登录相关的

### 手机上点微信登录，扫不了码

这是微信的设计，不是 bug：**微信的网站扫码登录在任何手机浏览器里都只给二维码**，而二维码就在你自己那块屏幕上，
自己扫自己的屏幕物理上做不到。

能走通的路：

1. **另一台设备的微信**扫这台手机屏幕上的二维码 → 扫完这台手机就登录了（用的还是原来的微信账号）
2. **在电脑上打开同一个网址**，点微信登录，用手机扫电脑屏幕 —— 这是最顺的
3. 懒得折腾 → 直接用手机号验证码登录

页面上的按钮已经写着「微信登录 · 用另一台设备扫码」，就是提醒这件事。

### 用手机号登录后数据是空的

**微信账号和手机号账号是两套独立身份**，平台不支持合并，数据天然不通。

如果你之前用微信登录过，数据在微信那套身份下；换成手机号登录会看到一个全新的空账号。

补救办法：在原来那套身份里「备份」导出 JSON，在新身份里「从备份恢复」导入。
或者干脆用回原来那种登录方式。

### 登录后换个标签页又要重新登录

这个环境不保存登录状态。常见于：

- 无痕 / 隐私模式
- 应用内嵌的预览窗口（不是真浏览器）
- 浏览器设置了「关闭页面即清除站点数据」

页面会在登录墙上方直接写出来。换成正常浏览器的新标签页打开即可。

### 手机号收不到验证码

- 确认是 11 位、没有空格
- 有些号码段有当日发送次数限制，等一会儿再试
- 收不到就换微信登录（如果条件允许）

## 数据相关的

### 加了数据，刷新就没了

两个原因，都指向同一个结果：

| 原因 | 怎么确认 |
|---|---|
| 处于演示模式（数据只在本浏览器） | 左上角写「演示数据 · 仅本机」 |
| 写进了别人的库，被权限过滤掉 | 左上角写「云端」，但数据不出现 |

第二种更麻烦：写入请求发出去了，返回也像成功，但数据库的行级安全把它过滤掉了
（`owner_id` 和你的登录身份不匹配）。检查 `endpoint` 和 `publishableKey` 是否属于**同一个应用**，
而且这个应用是你自己创建的。

### 报错 `42501`

缺表授权。`schema.sql` 里的 `grant` 语句没执行。

这不是策略写错了，是**两道门只过了一道**：policy 决定"能看到哪些行"，grant 决定"能不能碰这张表"。

补跑 `schema.sql` 第 11–15 条即可。

### 报错 `null value in column "owner_id"`

你在用 SQL 工具直接写库，而没带 `owner_id`。

通过页面正常写入时，`owner_id` 由数据库默认值 `auth.uid()` 自动填。
但 SQL 工具那条通道不经过登录态，`auth.uid()` 是空的，必须自己显式写。

### 时间差了 8 小时（下午 3 点就显示逾期）

写库时用了 ISO 格式。页面解析时间只认字面值，不做时区换算：

```
对：2026-10-25 23:59
错：2026-10-25T23:59:00.000Z
```

### 课表显示「第 N 周」但课不对

「第几周」靠**学期锚点**算：设置错了，整季都会偏。

点课表页的齿轮图标 → 学期设置 → 填**这学期第 1 周的任意一天**，会自动对齐到那一周的周一。

导入备份时锚点会跟着走，所以换设备一般不会错位。

### 数据能恢复吗

没有云端回收站。误删就是删了。

养成习惯：重要时间点用顶栏「备份」导出一份 JSON 存着。
「数据与账号」抽屉里可以导回来（云端是**追加**，本机模式是**替换**）。

## 功能相关的

### 课表截图识别用不了

AI 识别只在**云端模式**开放。演示模式下这个按钮不会给你结果。

### 邮件没收到

按这个顺序查：

1. 网页「邮件提醒」页的总开关开了吗？邮箱填了吗？
2. 手动跑 `node tools/daily_mail.js --data data.json`，能生成 `mail.html` 吗？
3. 加 `--send` 能收到吗？收不到就是 SMTP 的问题（授权码、环境变量）
4. 都正常但还是没自动发 → 定时任务没建，或者建的时候电脑没开

`remind_settings.last_push` 是今天的日期，说明今天已经发过了，会跳过。

### 机器人不说话

见 [QQ 机器人 · 四个已知的失灵方式](04-QQ机器人.md#四个已知的失灵方式)。
最常见的是「获取群内全部消息」被打开了，或者长连接僵死需要手动重连。

### 群里的消息进了收件箱，但 DDL 页没有

那条被判定成「不明确」，挂在 `待处理` 等你确认。看它的备注，补一句明确信息再发。

## 维护相关的

### 上游更新了，怎么同步

替换 `campus-workbench.html` → **把 `CLOUD_CFG` 两个值填回你的** → 重新发布。

不填就会退回演示模式，看起来像"数据全没了"（其实只是没连上）。

### 换域名 / 换应用

`endpoint` 和 `publishableKey` 必须成对换，而且要属于同一个应用。
只换一个的结果是：能登录，但读写全失败。

### 想改配色 / 加字段

见 [二次开发](07-二次开发.md)。加字段要三处一起改，只改一处会出现「读不到」或「写入报错」。

## 还是不行

按这个顺序收集信息，能定位绝大多数问题：

1. 左上角写的是哪种数据源（云端 / 演示数据 / 未登录）
2. 浏览器 F12 → Console 里有没有红色报错
3. F12 → Network 里失败的请求，状态码是多少
4. 是"写不进去"还是"写进去看不见"——这两件事原因完全不同
